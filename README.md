# Geek Season — документация проекта

Веб-платформа для подготовки к **ЕГЭ по информатике**. Ученик входит через
Telegram-бота, решает задачи-прототипы по номерам экзамена и видит свой прогресс:
что решено, точность, серию дней, слабые места. Следующий этап — репетитор
со своими группами учеников, пробные экзамены с таймером, рейтинг.

## Состояние на 22.10.2026

| Возможность | Статус |
|---|---|
| Вход через Telegram-бота (QR-код или 6-значный код) | ✅ |
| Банк номеров ЕГЭ (1–27) и задач-прототипов | ✅ |
| Проверка ответа: число, слово, несколько чисел | ✅ |
| Фильтры: источник задачи, решённые / нерешённые, сортировка | ✅ |
| Сохранение ответов и статистика в профиле | ✅ |
| «Что повторить» — слабые номера в профиле | ✅ |
| Пробный экзамен с серверным таймером, первичные и тестовые баллы (шкала 2026), разбор | ✅ |
| Рейтинг за неделю и за всё время (Redis) | ✅ |
| Запуск всей системы одной командой `docker compose up` | ✅ |
| Роли: управлять банком задач может только админ; редактор задач на сайте | ✅ |
| Автотесты backend (147 шт.) | ✅ |
| Картинки к условию и файлы к заданию (xlsx, txt…) загружаются в редакторе | ✅ |
| Достижения и уведомления в Telegram через RabbitMQ: повторы с паузой, «мёртвые письма», без дублей | ✅ |
| Номера 19–21: одна игра и три вопроса со своими ответами; полный пробник — 27 позиций, 29 баллов | ✅ |
