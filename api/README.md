# Контракты API

Источник правды — код: FastAPI строит схему OpenAPI из Pydantic-схем.
Живая документация с кнопками «Try it out»: <http://localhost:8000/docs>.
Снимок схемы на 09.11.2026 (версия API 0.14.0): [openapi.json](openapi.json) (можно открыть в <https://editor.swagger.io>).

Авторизация: заголовок `Authorization: Bearer <JWT>`, токен выдаётся после входа через Telegram.
🔓 — доступно всем, 🔒 — нужен вход, ◐ — работает для всех, но вошедшему отдаёт больше.

## Номера и задачи

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/numbers` | ◐ | Номера ЕГЭ по порядку, число задач; вошедшему — `solved` | 200 |
| GET | `/numbers/{code}/tasks` | ◐ | Прототипы номера без ответов. Параметры: `source` (`demo`, `official`, `approbation`, `author`), `sort`, `progress` (🔒), `limit`, `offset`. Вошедшему — `status` у задач | 200, 401, 404, 422 |
| GET | `/tasks/{id}` | ◐ | Одна задача без ответа; `solution_available` — можно ли открыть разбор | 200, 404 |
| POST | `/tasks/{id}/check` | ◐ | Проверить ответ `{"answer": "2 20"}` (до 255 символов — и здесь, и у правильного ответа задачи, и в пробнике и домашках); у задачи 19–21 — `{"answers": {"19": "29", "20": "28 48", "21": "44"}}`, в ответе `parts` с проверкой каждого вопроса; у вошедшего — сохранить попытку. Неверный ответ — без `correct_answer` и `explanation` (null), с `attempts_left`. Вошедшему: `pts_delta` (изменение PTS; null — повторная попытка, тогда `pts_repeat: true`), `rank_up` — новый ранг | 200, 404, 422 |
| GET | `/tasks/{id}/solution` | ◐ | Правильный ответ и разбор (у 19–21 — по частям): если задача решена или неверных ответов ≥ 3 (`REVEAL_AFTER_WRONG`). Вошедшему считаются попытки в базе, гостю — в Redis по адресу | 200, 403, 404 |
| GET | `/tasks/{id}/admin` | 👑 | Задача целиком, с ответом и разбором | 200, 401, 403, 404 |
| GET | `/tasks/by-external/{external_id}` | 👑 | Импортированная задача по id во внешнем банке (например, `kompege:31499`), включая архивные — чтобы повторный импорт не создавал дублей | 200, 401, 403, 404 |
| POST | `/tasks` | 👑 | Создать задачу. Необязательный `external_id` — id во внешнем банке при импорте; задача с таким же `external_id` уже есть — 409 | 201, 401, 403, 409, 422 |
| PATCH | `/tasks/{id}` | 👑 | Изменить присланные поля | 200, 401, 403, 404, 422 |
| DELETE | `/tasks/{id}` | 👑 | Убрать в архив | 204, 401, 403, 404 |
| POST | `/tasks/{id}/files` | 👑 | Загрузить картинку или файл к заданию: форма `multipart/form-data`, поля `file` и `kind` (`image` / `attachment`) | 201, 401, 403, 404, 422 тип, размер или лимит |
| DELETE | `/tasks/{id}/files/{file_id}` | 👑 | Удалить картинку или файл (из базы и с диска) | 204, 401, 403, 404 |
| GET | `/files/{имя}` | 🔓 | Картинка открывается в браузере, файл к заданию скачивается с исходным именем | 200, 404 |

У задач в ответах есть списки `images` и `attachments`: `{id, kind, name, url, size, content_type}`;
`url` — путь в API, например `/files/3f2a….xlsx`. Те же списки — у позиций пробника.

👑 — только роль `admin`: гость получает 401, ученик — 403.

Заблокированный ученик получает `403 «Аккаунт заблокирован»` на любой запрос со своим токеном и при входе
(`POST /auth/code`, `GET /auth/telegram/status`); бот отвечает ему, что аккаунт заблокирован.

## Админка

Любой админ может всё. Каждое изменение пишется в журнал `admin_actions`.

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/admin/users` | 👑 | Список учеников `{total, items}`. Параметры: `q` (имя, ник, @username, Telegram ID, id), `filter` (`all`, `admins`, `blocked`, `no_rank`), `sort` (`new`, `recent`, `pts`, `solved`, `name`), `limit`, `offset` | 200, 401, 403, 422 |
| GET | `/admin/users/{id}` | 👑 | Карточка: профиль, PTS ± RD, ранг, прогноз (`forecast_primary`, `forecast_score`), `calibrated_at`, статистика, `admin_from_env`, последние 10 действий админов | 200, 401, 403, 404 |
| PATCH | `/admin/users/{id}` | 👑 | Меняются присланные поля: `nickname` (правила как у ученика; `null` — сбросить), `created_at` (не в будущем), `role` (`student` / `admin`; свою нельзя), `blocked` (себя и админа нельзя). Ответ — карточка | 200, 401, 403, 404, 422 |
| POST | `/admin/users/{id}/pts` | 👑 | `{"pts": 1500}` — выставить PTS (ранг — по прогнозу) или `{"rank": "hero"}` — выбрать ранг (PTS подбирается под середину ранга). Ученик становится откалиброванным | 200, 401, 403, 404, 422 |
| POST | `/admin/users/{id}/recalibrate` | 👑 | Сбросить калибровку: ранг пропадает, следующий завершённый пробник снова входной | 200, 401, 403, 404, 422 нечего сбрасывать |
| POST | `/admin/users/{id}/reset-stats` | 👑 | Удалить ответы, пробники, PTS, достижения; ученик пропадает из рейтинга. Ответы в домашках стираются, «сдано» снимается — домашки можно решить заново. Профиль остаётся | 200, 401, 403, 404 |
| DELETE | `/admin/users/{id}/avatar` | 👑 | Сбросить аватарку (как `/auth/users/{id}/avatar`, но возвращает карточку) | 200, 401, 403, 404 |
| GET | `/admin/actions` | 👑 | Журнал, новые сверху: `{items: [{id, action, text, details, created_at, admin, user}], next_before}`. Параметры: `user_id`, `admin_id`, `before` (id для следующей страницы), `limit` | 200, 401, 403 |

### Домашки

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/admin/homework` | 👑 | Все домашки, черновики сверху: `title`, `sent_at` (`null` — черновик), `numbers`, `tasks_count`, `students_count`, `submitted_count` | 200, 401, 403 |
| POST | `/admin/homework` | 👑 | Черновик `{title, comment, task_ids, user_ids}`: задачи по порядку, без повторов и архивных | 201, 401, 403, 422 |
| GET | `/admin/homework/{id}` | 👑 | Для конструктора: задачи (`tried_by` — кто из учеников домашки уже решал), ученики | 200, 401, 403, 404 |
| PATCH | `/admin/homework/{id}` | 👑 | Черновик — любые поля; отправленная — только `title`, `comment` | 200, 401, 403, 404, 409 задачи/учеников после отправки, 422 |
| POST | `/admin/homework/{id}/send` | 👑 | Отправить (нужны ≥ 1 задача и ≥ 1 ученик) | 200, 401, 403, 404, 409 уже отправлена, 422 |
| POST | `/admin/homework/{id}/students` | 👑 | Добавить учеников `{user_ids}`; уже назначенные пропускаются | 200, 401, 403, 404, 422 |
| DELETE | `/admin/homework/{id}` | 👑 | Удалить у всех; попытки и PTS учеников остаются | 204, 401, 403, 404 |
| GET | `/admin/homework/{id}/results` | 👑 | Таблица «ученик × задача»: `tasks`, `rows` — `student`, `submitted_at`, `answered`, `correct`, `cells` (`{answer, is_correct, parts, answered_at}` или `null`) | 200, 401, 403, 404 |
| GET | `/admin/homework/tasks` | 👑 | Банк для конструктора: `number`, `q` (поиск по тексту условия), `user_ids` (повторяемый: отметить `tried_by`), `limit`, `offset` → `{total, items}`; без архивных | 200, 401, 403 |
| POST | `/admin/homework/random` | 👑 | `{number, count, user_ids, exclude_task_ids}` → случайные задачи номера, которых нет в домашке и которые никто из `user_ids` не решал | 200, 401, 403, 422 нет номера |

Задачу из домашки нельзя удалить из базы (`ON DELETE RESTRICT`); `DELETE /tasks/{id}` по-прежнему переносит её в архив, и в домашке она остаётся.

`text` — действие словами без имени админа: «изменил PTS: 0 → 1200», «сбросил калибровку (был ранг: Рекрут)».
Правки PTS (`pts.set`, `pts.rank`, `pts.recalibrate`, `stats.reset`) — ещё и события пересчёта PTS:
при пересчёте с нуля (запуск сервера) они повторяются по времени вместе с ответами и не пропадают.

## Домашки

Домашку собирает админ из задач банка и отправляет выбранным ученикам (админу тоже можно). Черновик и чужая домашка — 404.
На каждую задачу **одна попытка**: верно или нет — сразу, правильный ответ и разбор — только после сдачи.
Ответ засчитывается как обычный ответ на задачу: строка в `attempts`, PTS, статистика, событие `task.answered`. Строка домашки, попытка и PTS пишутся одним коммитом — двойной клик не начислит PTS дважды.

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/homework` | 🔒 | Мои домашки: `id`, `title`, `comment`, `numbers` (коды номеров), `total`, `answered`, `correct`, `sent_at`, `submitted_at` (`null` — не сдана). Несданные сверху | 200, 401 |
| GET | `/homework/{id}` | 🔒 | Домашка: `items` по порядку — `task` (как `GET /tasks/{id}`, архивные тоже), мой `answer`, `is_correct` (`null` — не отвечал), `parts` (ответы 19/20/21), `solution` (ответ и разбор — только после сдачи) | 200, 401, 404 |
| POST | `/homework/{id}/tasks/{task_id}/answer` | 🔒 | Единственная попытка: `{"answer": "42"}` или `{"answers": {"19": "…", "20": "…", "21": "…"}}`. Ответ: `is_correct`, `parts` (верность частей), `pts_delta`, `pts_repeat`, `rank_up`; без правильного ответа | 200, 401, 404 нет домашки / задачи в ней, 409 уже отвечено / домашка сдана, 422 формат |
| POST | `/homework/{id}/submit` | 🔒 | Сдать; можно с пропусками — они неверны в счёте домашки, но в `attempts` и PTS не пишутся. Ответ — домашка с разборами | 200, 401, 404, 409 уже сдана |

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/rating` | ◐ | Таблица лидеров по PTS, топ-20 (`limit` до 100). Параметры: `period` (`all` — по общему PTS, по умолчанию; `week` — по приросту PTS с понедельника, входной пробник и правки админа не в счёт), `number` (код номера: по PTS в номере; только с `period=all`), `rank` (фильтр: место внутри ранга). Ни PTS, ни прогноза, ни пробников, ни @username; заблокированный — 404 | 200, 404 |

## Достижения и уведомления

| Метод | Адрес | | Что делает | Ответы |
|---|---|---|---|---|
| GET | `/me/achievements` | 🔒 | Все 8 достижений: `received_at` — дата получения или `null` | 200 |
| GET | `/me/notifications` | 🔒 | Последние уведомления: текст, `sent_at` или `error` | 200 |

Достижения выдаёт не API, а фоновый воркер по событиям из RabbitMQ:

| Событие | Кто публикует | Поля | Очереди |
|---|---|---|---|
| `task.answered` | `POST /tasks/{id}/check` (вошедший), `POST /homework/{id}/tasks/{task_id}/answer` | `user_id, task_id, is_correct, first_solve` | achievements |
| `exam.finished` | `POST /exam/{id}/finish` | `user_id, session_id, primary_score, max_score, test_score` | achievements, notifications |
| `achievement.granted` | воркер | `user_id, code, icon, title, description` | notifications |

В каждом событии ещё `event, event_id, at`. Ошибка обработки → `<очередь>.retry` (5 с) → до 3 повторов → `geek.dead`.

## Примеры

`POST /tasks/8/check`

```json
// запрос
{ "answer": "2 20" }

// ответ 200 — верно: сразу ответ и разбор
{
  "task_id": 8,
  "is_correct": true,
  "correct_answer": "2 20",
  "explanation": "Суммы пар: 8, 13, 20, 19. Чётные — 8 и 20: их две, максимальная 20.",
  "parts": [],
  "solution_available": true,
  "attempts_left": 0
}

// ответ 200 — неверно: без ответа и разбора, пусть ученик подумает ещё
{
  "task_id": 8,
  "is_correct": false,
  "correct_answer": null,
  "explanation": null,
  "parts": [],
  "solution_available": false,
  "attempts_left": 2
}
```

После трёх неверных ответов `solution_available: true`, сайт показывает кнопку «Показать ответ и разбор» → `GET /tasks/8/solution`. Посмотреть ответ не запрещено: решить задачу потом можно как обычно, с очком в рейтинг.

`GET /me/stats` (сокращено)

```json
{
  "solved_tasks": 2, "total_tasks": 8,
  "total_attempts": 4, "correct_attempts": 3, "accuracy": 0.75,
  "streak_days": 1,
  "activity": [{ "date": "2026-10-22", "attempts": 4, "correct": 3 }],
  "by_number": [{ "code": "5", "title": "Системы счисления", "tasks_count": 1, "attempted": 1, "solved": 1 }],
  "recent": [{ "task_id": 2, "exam_number": "5", "answer": "22", "is_correct": true, "created_at": "..." }]
}
```

## Коды ответов

| Код | Значение |
|---|---|
| 200 / 201 / 204 | Успех (неверный ответ ученика — тоже 200, результат в `is_correct`) |
| 400 | Неверный или устаревший код входа |
| 401 | Нужно войти / токен недействителен |
| 403 | Нет прав (например, ученик пытается изменить банк задач) |
| 404 | Нет такого номера или задачи |
| 422 | Неверный формат данных (Pydantic) |
| 409 | Конфликт: время пробника вышло, пробник уже завершён или уже создаётся |
| 429 | Слишком много попыток ввода кода |
| 503 | Вход через Telegram не настроен (нет `BOT_USERNAME`) |
